# Maroc Bridges

Het roadtrip-avontuur door Marokko, als game: intro, 3D-kaart met de route en de vijf slaapplekken, een vlucht vanuit Nederland en per plek een straatkaart met de slaapplek. Statische web-app; open index.html via GitHub Pages. De oude gids staat nog in classic.html.

3D: three.js. Kustlijnen: Natural Earth via world-atlas. Straatkaarten: © OpenStreetMap contributors, © OpenMapTiles. Lettertypes: Lilita One en Nunito (SIL Open Font License).
